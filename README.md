# Catálogo MDX

- Catálogo para clientes: https://gaston-lizondo.github.io/mdx-catalogo/
- Catálogo interno (con acceso): https://gaston-lizondo.github.io/mdx-catalogo/interno/

El catálogo interno está encriptado (AES-GCM, clave derivada con PBKDF2): sin usuario y contraseña el contenido no se puede leer.
